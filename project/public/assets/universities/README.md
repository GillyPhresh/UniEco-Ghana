# University branding assets

These are local fallback copies collected from the universities' publicly linked official websites. The manifest at `project/data/university-branding.json` records the source page, original URL, content type, byte size, and SHA-256 hash for each file.

The database branding fields remain authoritative. If an authorized university administrator uploads a newer logo or landmark image, the application uses the database URL first and falls back to these local files only when that field is empty.

Official marks and photographs remain subject to each institution's terms and intellectual-property rights. Do not reuse them outside UniEco Ghana without permission. Institutions without an accessible official asset source are deliberately left on the application's monogram/campus placeholder until an authorized source is supplied.

The Spiritan University College crest fallback is sourced from the institution's official website at `https://suc.edu.gh/wp-content/uploads/2025/04/cropped-logo-1.jpg`.
